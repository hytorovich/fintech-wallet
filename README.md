Fintech Wallet

A simple Java Core project that simulates basic banking operations.

Features
 Create users and accounts
 Deposit and withdraw money
 Validate transaction amounts and account balance
 Store transaction history

Technologies
 Java
 BigDecimal
 Gradle
 JUnit 5

How to Run
Open the project in IntelliJ IDEA and run `Main.java`.
